# 内部数据看板与进度追踪平台

> 一个面向区县涉农主管部门的内部数据看板与 AI 分析工具。本项目用于产品/AI 产品经理实践，**对外展示（作品集）使用脱敏数据与脱敏地名**。

## 项目定位

- **产品形态**：内部效率工具 / 政务数据看板
- **核心价值**：把分散在各部门 Excel 中的进度数据聚合起来，让领导无需开会即可通过 AI 分析快速掌握全局、发现异常。
- **AI 设计原则**：固定分析 + 对话式分析双通道；所有 AI 结论必须可溯源、经人工确认（HITL）。
